# Reporting a security issue

Use [GitHub private vulnerability reporting](https://github.com/jatayuos4u/jatayu-lekh/security/advisories/new) if available. If the form is unavailable, use the contact information on the [JatayuOS website](https://jatayuos.in/) to request a private reporting channel.

Include the installed Lekh version, OS version, affected feature, and a description of the behavior. Remove private document contents and personal information from attachments.
